# Transaction-Fraud-Detection-and-Risk-Analysis

This project detects fraudulent financial transactions using Machine Learning and visualizes fraud patterns using Power BI.

## Technologies Used
- Python
- Pandas
- Scikit-learn
- Random Forest
- SMOTE
- Joblib
- Power BI
- SQL

## Project Workflow
1. Data cleaning and preprocessing
2. Feature engineering
3. Handling class imbalance using SMOTE
4. Model training using Random Forest
5. Model evaluation
6. Power BI dashboard creation

## Model Performance
- Accuracy: 47.5%
- Recall: 60.3%
- Precision: 32.8%
- False Positive Ratio: 67.2%
- ROC AUC: 0.51

## Dashboard Pages
1. Transaction Fraud Detection
2. Behaviour & Risk Analysis
3. ML Model Performance

## Conclusion
This project successfully developed a machine learning-based fraud detection system and interactive Power BI dashboards to analyze transaction behavior and identify fraudulent activities. The model effectively detected suspicious transactions, while the dashboards provided valuable insights into fraud patterns, risk factors, transaction trends, and model performance. Overall, the project demonstrates the practical application of data analytics, machine learning, and business intelligence for supporting fraud monitoring and decision-making in financial systems.
